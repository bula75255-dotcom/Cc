# BaconSingleBypass

Theos project for GitHub Actions.

1. Upload this folder to a GitHub repository.
2. Open Actions -> Build BaconSingleBypass.
3. Run workflow.
4. Download the `BaconSingleBypass-build` artifact.

The source opens the Bacon Bypass webpage and can fill a URL field.
Human verification/CAPTCHA is intentionally left for the user.
The project does not contain an API key and does not automate CAPTCHA bypass.

`BaconShowMenu()` is exposed for integration with an existing tweak.
